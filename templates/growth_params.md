# 8种估值模型 -- 完整参数参考表

本文档为 `build_report.py` 支持的全部 8 种估值模型提供参数参考，包括因子权重、适用行业、PE/PB 自动区间口径、可选因子输入方式及缺失处理规则。

> **2026-09-10 口径更新：** 因子权重以 `scripts/scoring_engine.py` 的 `MODEL_PRESETS` 为准——2026-09 审计后每模型收敛为 **5 因子**（量能 IC≈0、波动率 IC 为负，均已剔除）；PE/PB 评分自 2026-08 起用**历史百分位 rank 映射**（自动区间），2026-09 起盈利换挡窗口自动处理，`--pe/--pb` 仅为单次逃生阀。第二、三、四、五、六节已按现行口径改写；第八、九节为带日期的设计记录与案例，其中历史数字按当时口径标注，仅作方法参考。

## 一、模型总览与适用场景

| 模型标识 | 模型名称 | 适用行业 | 核心特征 |
|----------|----------|----------|----------|
| `staples` | 必选消费 | 食品饮料、乳制品、调味品、文具、日用品 | 业绩稳定、现金流好、防御性强、需求刚性 |
| `discretionary` | 可选消费 | 免税旅游、白酒、家电、服装、珠宝 | 品牌溢价明显、受消费周期影响、PEG敏感 |
| `tech` | 科技制造 | 半导体、汽车零部件、湿电子化学品、软件 | 高研发投入、增速快、PEG权重最高 |
| `cyclical` | 周期资源 | 有色金属、航运、化工、煤炭、钢铁 | 业绩随商品价格大幅波动、需追踪商品价格位置 |
| `soe` | 央企基建 | 建筑、基建、电力、交运、电信 | 股息率高、订单驱动、PB估值为主 |
| `bank` | 银行保险 | 银行、保险、券商 | PB为核心、ROE和不良率决定估值、PE权重为0 |
| `realestate` | 地产 | 房地产开发、物业管理 | NAV折价为核心、去化率和杠杆率为关键 |
| `pharma` | 医药消费 | 化学制药、中药、医疗器械、医疗服务 | 营收增速权重高、受政策周期影响大 |

### 模型选择指南

1. **业绩稳定增长、现金流好** --> `staples` 或 `pharma`
2. **品牌驱动、PEG敏感** --> `discretionary`
3. **高研发、高增速** --> `tech`
4. **随商品价格/宏观经济波动** --> `cyclical`
5. **高分红、央国企、订单驱动** --> `soe`
6. **金融行业（银行/保险）** --> `bank`
7. **房地产开发** --> `realestate`
8. **医药/医疗** --> `pharma`

> 旧版 `growth` 模型已自动映射为 `staples`，保持向后兼容。

## 四、因子说明与输入方式

### 4.1 因子分类

全部因子分为两类：

**基础因子**（由K线数据自动计算，无需额外输入）：

| 因子名 | 代码键 | 计算来源 |
|--------|--------|----------|
| PE(TTM) | `pe` | 当日不复权真实价 ÷ 已生效 EPS（T年年报次年5月生效，送转/派息逐日重述）；腾讯 qt[39] 仅作当前值兜底 |
| PB | `pb` | 当日不复权真实价 ÷ 已生效 BPS（同上逐日重述）；腾讯 qt[46] 仅作当前值兜底 |
| PEG | `peg` | PE(TTM) / (预期增速 * 100) |
| MA偏离度 | `ma` | 收盘价偏离MA20/MA60的百分比 |

> 量能（vol）与波动率（vola）因子已于 2026-09 经 IC 审计从预设剔除（函数保留兼容）；波动率现行口径为 20 日滚动收益率标准差（非旧版单日振幅）。

**可选因子**（需要通过命令行 `--键:值` 格式额外输入，未传的自动从 iFinD 财报填充）：

| 因子名 | 代码键 | 输入格式 | 单位 | 说明 |
|--------|--------|----------|------|------|
| 商品价格偏离 | `commodity_dev` | `--commodity_dev:-0.15` | 小数 | 当前商品价格相对历史均值的偏离度，负值=低于均值（低估信号）。例如铜价历史均值7万，当前5.95万，输入 `-0.15` |
| 产能利用率 | `capacity_util` | `--capacity_util:0.85` | 小数(0-1) | 当前产能利用率百分比。例如85%输入 `0.85`（当前预设不使用，键保留兼容） |
| ROE | `roe` | `--roe:0.15` | 小数 | 净资产收益率；不传则自动填充近5年报均值。例如15%输入 `0.15` |
| 股息率 | `dividend_yield` | 优先 `--dps 0.80` | 元/股 | 传每股年分红后按 `dps/当日价` 逐日动态计算（推荐）；直接传 `--dividend_yield:0.05` 为恒定值兜底 |
| 不良/偿付 | `npl_ratio` | `--npl_ratio:0.012` | 小数 | 不良贷款率。例如1.2%输入 `0.012` |
| NAV折价 | `nav_discount` | `--nav_discount:0.7` | 小数 | 股价/每股NAV的比值。低于1为折价。输入 `0.7` 表示折价30% |
| 去化率 | `clearance_rate` | `--clearance_rate:0.65` | 小数(0-1) | 当前在建项目去化率。例如65%输入 `0.65` |
| 杠杆率 | `leverage` | `--leverage:0.55` | 小数(0-1) | 有息负债率。例如55%输入 `0.55` |
| 研发费用率 | `rd_ratio` | `--rd_ratio:0.08` | 小数 | 研发费用/营业收入。例如8%输入 `0.08` |
| 毛利率稳定性 | `margin_stability` | `--margin_stability:0.02` | 小数 | 近5年毛利率的标准差（自动填充），越小越稳定。输入 `0.02` 表示标准差2个百分点 |
| 品牌溢价度 | `brand_premium` | `--brand_premium:1.8` | 小数 | 公司毛利率 / 行业平均毛利率。输入 `1.8` 表示毛利率是行业均值的1.8倍 |
| 订单增速 | `order_growth` | `--order_growth:0.20` | 小数 | 新签合同/订单同比增速。例如20%输入 `0.20` |
| 营收增速 | `revenue_growth` | `--revenue_growth:0.18` | 小数 | 最新营收同比增长率（自动填充）。例如18%输入 `0.18` |

### 4.2 命令行输入示例

```bash
# cyclical 模型：输入商品价格偏离（现价较历史均价低10%）
python scripts/build_report.py 601899 --model cyclical --commodity_dev:-0.10 --dps 0.80

# soe 模型：每股年分红 + 订单增速
python scripts/build_report.py 601668 --model soe --dps 0.62 --order_growth:0.12

# bank 模型：手动 ROE、不良率（覆盖自动填充值）
python scripts/build_report.py 601398 --model bank --roe:0.11 --npl_ratio:0.012

# tech 模型：输入研发费用率
python scripts/build_report.py 688041 --model tech --rd_ratio:0.28

# staples 模型：全自动（毛利率稳定性自动从财报填充）
python scripts/build_report.py 603899 --model staples
```

> 人工参数（growth/dps/因子/副标题）由 `meta.param_source` 标记来源，下次无参运行自动恢复；`--pe/--pb` 为单次逃生阀，不持久化。

## 五、可选因子缺失时的处理规则

### 5.1 处理逻辑

当某个可选因子未被用户输入（缺失）时，系统按以下规则处理：

1. **识别缺失因子**：遍历模型权重组，找出用户未提供值（`None`）且权重 > 0 的可选因子
2. **计算缺失权重总和**：将所有缺失因子的权重累加，记为 `missing_weight_sum`
3. **按比例重分配**：将 `missing_weight_sum` 按比例分配到已有值的因子上
4. **归一化**：重新归一化所有活跃因子权重，确保总和 = 1（即100%）

### 5.2 重分配公式

```
对于每个有值的因子 k：
  新权重 = 原权重 + 原权重 / 活跃因子权重总和 * 缺失权重总和

归一化后：
  最终权重 = 新权重 / 所有新权重之和
```

### 5.3 示例

**bank 模型全部因子齐全时：**
```
PB(32.6%) + ROE(27.2%) + 股息率(16.3%) + 不良/偿付(13%) + MA偏离(10.9%) = 100%
```

**bank 模型缺失 `roe` 和 `npl_ratio` 时：**
```
缺失权重 = 27.2% + 13% = 40.2%
活跃因子原权重 = 32.6% + 16.3% + 10.9% = 59.8%

重分配后：
  PB = 32.6% + 32.6%/59.8% * 40.2% = 54.5%
  股息率 = 16.3% + 16.3%/59.8% * 40.2% = 27.3%
  MA偏离 = 10.9% + 10.9%/59.8% * 40.2% = 18.2%

归一化后（总和已是100%）：
  PB(54.5%) + 股息率(27.3%) + MA偏离(18.2%) = 100%
```

**cyclical 模型缺失 `commodity_dev` 时：**
```
缺失权重 = 24.1%
活跃因子原权重 = 30.1% + 14.4% + 18% + 13.4% = 75.9%

重分配后：
  PE = 30.1% + 30.1%/75.9% * 24.1% = 39.7%
  PB = 14.4% + 14.4%/75.9% * 24.1% = 19.0%
  MA偏离 = 18% + 18%/75.9% * 24.1% = 23.7%
  股息率 = 13.4% + 13.4%/75.9% * 24.1% = 17.7%

归一化后：
  PE(39.7%) + PB(19%) + MA偏离(23.7%) + 股息率(17.7%) = 100%
```

### 5.4 影响评估

| 缺失因子数量 | 对评分精度的影响 | 建议措施 |
|-------------|-----------------|----------|
| 0个缺失 | 最精确 | 完整使用所有因子 |
| 1-2个缺失 | 轻微影响，偏差约5-10分 | 核心因子（高权重）齐全即可接受 |
| 3个及以上缺失 | 中等影响，偏差约10-20分 | 建议至少输入模型中权重最高的2个可选因子 |
| 全部可选因子缺失 | 仅使用预设内的价格/K线因子（PE/PB/PEG/MA偏离，视模型而定） | 可用，但会丢失行业特异性信息 |

### 5.5 特殊情况

- **bank 模型**：若所有可选因子缺失且未传 dps，退化为 PB+MA偏离 两因子，对金融行业精度不足，**强烈建议至少输入 ROE 与不良率（或传 --dps 使股息率生效）**
- **realestate 模型**：NAV折价/去化率/杠杆率全部缺失时退化为 PB+MA偏离，**强烈建议至少输入 NAV折价**
- **cyclical 模型**：商品价格偏离是周期定位的关键（产能利用率已于 2026-09 审计删除），缺失后将退化为通用模型，**推荐至少输入 commodity_dev**
- **各模型预设内的价格/K线因子（PE/PB/PEG/MA偏离）由K线自动计算**，不存在缺失问题；仅可选因子涉及缺失重分配

## 六、PE/PB 区间口径（自动，2026-08 起不再人工设定）

1. **评分映射默认历史百分位 rank**：当日 PE/PB 在全历史有效样本中的分位直接映射为因子分，极值区不触顶饱和
2. **盈利换挡窗口自动处理区间失真**：年报净利润 5 年段中位数比值 >3 记向上换挡，命中时 PE 分位只用换挡生效后子序列（对齐次年 5 月披露时点）；向下回落/亏损段/历史不足不切窗，原因记录在 `meta.window_reason`，亏损段在报告中有红色警示
3. **`--pe/--pb` 仅为单次逃生阀**：仅当次报告走线性映射，不持久化；人工区间会覆盖自动窗口，非必要不用
4. **增速假设**仍可 `--growth` 手动覆盖（参考第三节增速表）；扭亏/暴增（同比>500%）不适用线性假设，走估值消化曲线提示

## 八、盈利换挡自动检测（2026-08 复盘新增，2026-09 起引擎自动）

### 8.1 为什么要校准

自动 PE/PB 区间用全部 10 年数据的 10th/90th 百分位。若公司盈利发生 **regime 切换**（亏损↔微利↔暴利↔常态高盈利），全周期混算的区间会失真：

- 暴利年把 PE 区间拉得极低 → 常态盈利的 PE 恒超 90th → PE 因子恒 0 分 → 常年误判"高估"
- 微利/亏损年把 PE 区间拉得极高（韦尔 2016-2019 微利期 PE 100-300）→ 盈利正常化后 PE 恒低于 10th → PE 因子恒 100 分 → 误判"低估"（豪威集团案例：校准为近 2 年区间 PE 28-41 后，评分 58.8 无交易价值，全周期 70% 时间"高估"恢复正常）
- BPS 大幅增厚后（如中远海控 4 元→15 元），历史 PB 区间失效，当前 PB 恒超 90th

### 8.2 检测方法（引擎自动，无需人工）

引擎在评分前用年报净利润序列自动检测（`scoring_engine.detect_regime_window`）：

```
按序列首年对齐每 5 年一段，取段内净利润中位数（抗单年极端值）
比值 = 后段中位数 / 前段中位数
- 比值 > 3.0   → 向上换挡（取最后一次），PE 分位只用换挡后子序列
- 比值 < 1/3   → downward_skip，仅标注不切窗
- 任一段中位数 ≤ 0 → loss_period_skip，仅标注（报告红色警示）
- 段数 < 2（不足10年） → insufficient_history
```

### 8.3 处理方式（自动）

- 检测到向上换挡：PE 分位窗口起点对齐年报披露（T 年年报次年 5 月起）；PB 与其余因子维持全历史；窗口内 PE 样本 <50 天时 pe 因子计中性 50 分
- 向下回落/亏损段/历史不足：维持全历史，meta.window_reason 记录原因，HTML 标注
- --pe/--pb 为单次逃生阀（仅当次报告走线性映射），不再有持久化人工区间（2026-08 的 MANUAL_RANGES 已删除）

仍需人工保证：
- 周期股同步提供 `commodity_dev`（缺失时其 20% 权重摊到 PE，放大失真）
- 高股息公司提供 `dividend_yield`，破净公司提供 `roe`（补偿 PB 区间失真）
- 触发清单（regime_switch）逐只人工标注真伪：报表净利含一次性损益可能制造伪换挡

### 8.4 案例：中远海控（2026-08）

> 本案例发生在人工校准时期；校准做法已被 8.2/8.3 自动检测取代（2026-09），案例的 regime 分析框架仍有效。

| 阶段 | 时期 | 净利 | 状态 |
|------|------|------|------|
| regime A | 2016-2019 | -99 ~ 67 亿 | 亏损/微利 |
| regime B | 2020-2022 | 99 → 1096 亿 | 疫情暴利 |
| regime C | 2023-2026 | 240 ~ 491 亿 | 常态高盈利 |

- 全 10 年自动区间：PE 0.9-7.2（被 regime B 拉低）→ 常态 PE 7.9 恒超 90th，因子 0 分
- 校准后：PE 4-12、PB 0.7-1.4（只用 regime C 波动范围）+ soe 模型（股息率 6.5%、ROE 15%）
- 效果：评分 30 → 61，近两年"高估"天数从 74% 降到 0%，低估天数从 0 天恢复到 162 天

### 8.4b 案例：宏达股份 BPS 断裂（2026-08）

不仅净利有 regime，**BPS（每股净资产）也可能断裂**：

| 时期 | BPS | 事件 |
|------|-----|------|
| 2016-2017 | 2.32 ~ 2.43 元 | 正常 |
| 2019 | 1.13 元 | 金鼎锌业案败诉，计提减值 |
| 2021-2024 | 0.17 ~ 0.20 元 | 持续亏损侵蚀，净资产近枯竭 |

- 后果：自动 PB 区间 1.8-35（被断裂前高 BPS 污染），当前 PB 11-30 倍实为"壳+重组/铜矿期权"定价，PE/PB 全部失效，评分仅参考
- 识别方法：查 EPS/BPS 序列，若 BPS 某一年骤降 >50% 且此后长期低位 → BPS regime 断裂
- 处理：结论以定性为主（重组/题材/资产注入预期），评分仅作价格趋势参考

### 8.4c 案例：高成长周期股区间校准（2026-08）

> 宝丰/紫金当时靠手动区间校准；2026-09 起紫金由自动检测触发 2021 段换挡（分位窗口 2022 年 5 月起），宝丰未达 3.0 阈值走全历史，均不再需要人工区间。

盈利持续向上跃迁的周期成长股（如宝丰能源：2025 净利 +79%、2026H1 +63~78%），全 10 年 PE 区间同样失真（早期低盈利期 PE 极高，拉高区间上限）：

- 宝丰 10 年自动区间失真 → 手动指定近 5 年实际波动 PE 8-20、PB 1.5-5，分布恢复正常（85% 时间无交易价值档）
- 紫金矿业（净利 5 年增长 20 倍）：全 10 年区间致 PE/PB 双 0 分硬截断 → 改用近 2 年百分位 PE 8.3-18、PB 2.35-5.1，因子恢复区分度，评分 22 → 26（结论不变但展示合理）
- 处理：先用脚本算出近 3-5 年实际 PE/PB 百分位，再手动指定（不要拍脑袋）

### 8.5 适用性边界

- 仅向上换挡切窗；向下回落不切（周期底部若切到回落段，低分恰好出现在最该买入的位置）
- 盈利稳定的消费/医药/银行类公司不触发，全历史区间仍然有效
- 尾部残段（不足 5 年）不参与判定：最近 1-4 年内新发生的跃迁要等残段攒满才可检测（保守方向）
- 扣非净利暂未接入：一次性损益（大额减值/处置收益）可能制造伪换挡，靠触发清单人工标注拦截

## 九、股息率因子与 DPS 动态化（2026-08 方案 A 新增）

### 9.1 设计背景

周期股（cyclical）此前无股息率因子，高分红周期股（煤炭/航运）与低分红成长周期股（有色）在股东回报维度无区分度。方案 A 将 `dividend_yield` 纳入 cyclical 权重 10%，其余 7 因子按比例 ×0.9 保持总和 1.0（`resolve_active_weights` 仅在因子缺失时归一化，全因子时必须预设总和为 1）。

> 注：本节记录 2026-08 方案 A 落地时的 8 因子口径；2026-09 审计收敛为 5 因子后，cyclical 的股息率权重为 13.4%（见第二节）。打分分段与 DPS 动态机制不变。

### 9.2 打分规则（复用 score_dividend_yield 分段）

| 股息率 | 分数 | 语义 |
|---|---|---|
| ≥8% | 95 | 极高回报 |
| ≥6% | 85 | 高回报 |
| ≥4% | 70 | 良好回报 |
| ≥3% | 55 | 中等偏上 |
| ≥2% | 40 | 一般 |
| <2% 或缺失 | 30 | 低回报/中性（不惩罚） |

关键特性：低股息率给中性 30 而非低分——成长型周期股（紫金 1.7%）不被扣分；股息率是天然逆向指标（股价跌→股息率升→加分），与估值目标同向，无顺周期失真。

### 9.3 动态 DPS（A2 方案）

传 `--dps:每股年分红` 时，历史每日股息率 = dps/当日收盘价，逐日动态打分（历史低价区股息率自动升高→高分）；不传 dps 时退化为恒定当前股息率。`build_report.py` 自动用 `dps/现价` 填当前股息率（保证因子权重生效）。

### 9.4 DPS 口径与查证（重要）

- **口径统一**：最近 12 个月实际派现 ÷ 总股本（含中期+末期），如云铝 2025 年度 = 中期 10 派 3.2 + 末期 10 派 3.79 = 0.699 元/股
- **差异化分红**（宝丰能源）：末期中小股东 0.4921/大股东 0.3906 不同，用年度累计派现总额 ÷ 总股本（50.91 亿/73.33 亿 = 0.70 元）
- **不分红不传**：亏损/未分配利润为负的公司（宏达股份 2025 不分红，未分配利润 -55.96 亿）不传 --dps，避免低分占权重进一步拉低已失真的评分
- **必须查证公告**：不得按“搜索到的股息率 × 旧价格”反推 DPS（神火教训：按 16 元×3.8% 估出 0.61 元，实际现价 26.91、2025 年报 10 派 8 = 0.80 元，股息率 2.97% 而非 3.8%）
- 回购不并入 DPS（股东总回报可另在提示注释中说明）

### 9.5 影响量级（10% 权重实测）

| 股票 | 股息率 | 评分变化 |
|---|---|---|
| 紫金 1.7%→2.41% | 40 分 | +1.4 |
| 云铝 2.57% | 40 分 | +1.3 |
| 神火 2.97% | 40 分 | +1.0 |
| 中国神华 5.5% | 70 分 | +4.2 |
| 川恒 5.25% | 70 分 | +1.5 |
| 云天化 4.69% | 70 分 | +2.2 |
| 宝丰 2.94% | 40 分 | -0.2 |
| 垒知 1.95% | 30 分 | -2.6 |

有色板块股息率普遍 <3%，加分有限；煤炭/航运/磷化工高股息周期股受益显著。评分只会小幅上移，不会反转档位——高股息是加分项而非免死金牌。

**低股息边界**：垒知股息率 1.95%（分红率 101% 但净利仅 5412 万）得 30 分，评分 -2.6——低股东回报绝对值被小幅折价，属预期行为；1.95% 距 2% 档仅 0.05pp，分段边界效应显著，重跑前需核实 DPS 精确值。

**4.3 集中度提示**：近两年单档位 >70% 告警对估值稳定型股票（宝丰 87%/川恒 80%/云天化 96%/垒知 88%）天然误报——其因子分本集中于 40-69 档（40-69 档宽 30 分）；加 DPS 前后对比（无 DPS = 权重归一化反算）确认超线系股票自身属性（85%/92%/93%/90% 本就超线），非方案副作用；川恒/垒知集中度反而因 DPS 改善。

### 9.6 高估档提示注释的增速口径（2026-08 修复）

警告条出现条件：评分 <40（高估档）且（股息率 ≥3% 或 增速 >20%）。增速判据：**最新报告期净利润同比**（盈利动能），build_report.py 自动读取 `reports[0]['profit_yoy']`（--growth 手动覆盖），数据缺失时回退历史 CAGR（eps_growth）。

- 文案必须标注报告期（如"盈利增速约 151%（2026 中报同比）"），避免单期同比被误解为全年
- 同比 >500%（扭亏/低基数）仅定性描述为"大幅增长（低基数/扭亏）"，不显示具体数字
- **PEG 因子仍用 CAGR**：单期同比波动大（神火 +151% 会让 PEG=PE/151 失真），历史成长性与当前动能分工
- 神火案例：修复前用 2025 年报 CAGR（-7%）→ 警告条不出现；修复后自动读 2026 中报 +151% → 自动触发。云铝 2026Q1 +269%（低基数）同样自动识别并标注报告期
