# 仓位管理与交易模块设计参考

> 定稿 2026-09-12 ｜ 依据：2026-09-11/12 仓位管理变体回测（`scripts/backtest_position.py`，46 只 × 2008-05~2026-09，任意起点 1y/3y）
> 用途：未来交易模块的实现规格与设计依据。数字口径与局限见第六节，勿跳过。

## 一、要解决的三个问题

1. **信号太密，看不过来**：买入区（分数 ≥ 自身历史 p95）在任一时点覆盖全池约 2-7%（46 只中 1-3 只常态，密集期 25+ 只），弱段每个入场点首买 25-26 只。实际操作需要仓位与注意力约束。
2. **短历史伪信号**：次新股（上市 1-2 年）历史分数仅几十天，"比上市以来 95% 的日子便宜"容易达成，曾出现绝对分数 45（高估档）却 100% 分位触发买入的案例（香农芯创，后 -62%）。
3. **规则未定义的执行细节**：同日多候选先买谁？单股买到多少为止？每月能做几笔？

## 二、交易模式定义（可直接实现的规格）

### 信号层（与回测引擎一致，未改动）

- 买入区：分数 ≥ 自身历史 p95（年度切片 PIT 阈值，每年 5/1 重算，只用严格早于本切片的历史分数）
- 卖出区：分数 ≤ 自身历史 p10
- 中间区：**保持前态**（滞后机制的核心，见结论 3）

### 组合层（本次新增，事件驱动）

- 每日执行顺序：**先卖后买**（清仓释放额度与月度名额）
- **优先级**：当日买入区候选按**分数降序**执行（分数=低估综合分，最便宜先买）
- **四个闸门**（任一关上即停）：现金不足一笔 / 当月 3 笔用完 / 已持有 10 只（禁开新仓）/ 单只累计 30%
- 每笔 5% NAV；单股单日 1 笔；卖出=整仓
- 信号滞后 1 日（T-1 信号 → T 收盘成交）；单边成本 0.1%；现金不计息；停牌不交易（卖出信号挂起到复牌）
- **持续封顶（v1b）**：每日检查，单股 >30% 削峰回 30%（见结论 4）

## 四、结构性结论（未来模块的设计依据）

1. **分数优先级是主要增量来源，不是仓位限制本身。** v1 全期超额 +398%（v0 +284%），增量来自"每月 3 个名额 + 分数降序"迫使组合向最便宜的名字集中（深低估倾斜）。分层证据同向：80-100 分桶年化收益 +27.4% vs 60-80 分桶 +21.6%。

2. **绝对分数门槛（≥70）净效果为负，弃用。** v2 全期超额 +6%（vs v1 +398%），弱段 -24.2%。机制：周期股在景气底部盈利塌方 → EPS 掉 → PE 虚高 → **绝对分数反而低**——门槛系统性地挡住的恰恰是最好的周期底买点（实例：陕西煤业 43 分大底，后 +65%）。短历史伪信号的可行解法：①分数优先级天然把低分伪信号排到队尾（v1 的 145 笔买入中短历史仅 4 笔）；②可选"阈值样本 ≥250 天"（v3），代价是全部信号延迟约一年（+55%）。**不要用绝对分数做买入闸门。**

3. **稀疏信号下禁止"月度快照全量再平衡"，必须用滞后机制。** v4 失败（平均仓位仅 35%）的结构原因：买入区月均候选仅 1-3 只，按目标权重配不满；且月度清仓把 p10-p95 中间区持仓也扔掉，反复空仓。正确形态即 v1/v1b：**买入区进、卖出区出、中间区持有**——仓位管理与信号滞后是一体的。

4. **持续 30% 封顶优于"仅买入口封顶"。** v1 的 30% 只在买入时约束，赢家浮盈让单股漂移到 65%（集中度失控）。v1b 每日削峰：全期多赚 +127pp、回撤浅 3.9pp、单股峰值精确 30%。机制解释：翻倍的股票必然变贵，削峰=价值纪律的机械化止盈，回收现金换更便宜的名字。

5. **仓位变体有两类无法修复的弱点段**。①接刀市（2015-2016 / 2016-2018，-10%~-24%）：急跌中分数快速进入买入区属**信号层问题**，仓位管理解决不了；②快牛市起点（2012-2015，v1/v1b -41%/-48%）：慢建仓踏空单边上涨，是注意力约束的代价（v0 满仓跟随反而 +6.3%）。执行这套规则前对这两类时段要有明确预期。

6. **注意力约束有真实代价。** 每月 3 笔 × 5% = 每月最多建仓 15%，从零到 80% 仓位需 5-6 个月——1y 任意起点中位 -4.2%（v0 +1.9%）。从牛市起点入场，第一年注定踏空。执行这套规则就要接受建仓期慢。

## 五、推荐方案（未来交易模块 v1 规格）

信号层：95/10 PIT 百分位，中间区持有（与 run_backtest 一致）。
组合层：≤10 只、单只 ≤30% **持续封顶**、每笔 5% NAV、每月 3 笔、分数降序优先、先卖后买、信号滞后 1 日、0.1% 单边成本。

**下一轮回测清单（实现前应完成）：**

- [ ] 每月笔数敏感性（3 / 5 / 8）与每笔大小（5% / 10%）——注意力与建仓速度的权衡曲线
- [ ] 削峰参数：阈值（30% / 40%）与频率（每日 / 每周）
- [ ] 现金收益计入（货基 ~1.5% 年化），低仓位年份的影响
- [ ] 跌停无法卖出、长期停牌（重组）的执行层处理
- [ ] 卖出分位对称性（p10 / p20）在仓位框架下重验
- [ ] 样本外/滚动前置检验：本报告所有结论为样本内，7 变体选优存在多重比较，实盘前应在前推时段复核 v1b 排名稳定性

## 六、诚实披露

- **多重比较**：7 变体选 1 最优，+525% 是样本内单点数字，预期应打折；可信赖的是结构结论（第 1-4 条的方向性）。
- **幸存者偏差**：单一当前 watchlist（46 只），未含退市股。
- **近似**：成本 0.1% 单边近似、现金不计息、停牌日按 carried price 估值；30% 帽在成交时点校验。
- 口径：全期 2008-05~2026-09（数据到 2026-09-11），基准为等权闭眼持有；1y/3y 为季度入场任意起点含成本超额（百分点差，非收益率）。
