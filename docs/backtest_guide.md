# 估值回测报告阅读说明

> 本说明对应 `artifacts/backtest/{run_id}/backtest_report.html`（每次运行会复制一份 `reading_guide.md` 到报告同目录）。

## 一、这份报告回答什么问题

报告回答唯一一个问题：**"分数（0-100）是否预示未来收益？"**
评分模型声称"分数越低越低估、未来越可能上涨"。本报告用历史数据检验这句话：

- 分数高的样本，未来 60/250 个交易日收益是否真的更高？（**分层回测**）
- 分数与未来收益是否存在稳定的统计关联？（**IC 检验**）
- 按分数买卖能否跑赢买入持有？（**策略模拟**）

所有历史分数都是 **Point-in-Time（PIT）** 口径重算的：只用"当时已披露"的数据（财务年报滞后生效、估值区间滚动重算、禁止当前值反推），不含未来函数。

## 二、报告结构

| 章节 | 内容 | 核心问题 |
|------|------|----------|
| 1. 组合策略 vs 基准净值 | 两种策略净值曲线与指标 | 按分数交易能不能跑赢持有？ |
| 2. 分层回测 | 分数分桶的未来收益 | 分数对收益有没有区分度？ |
| 3. IC 检验 | 分数-收益相关性与散点 | 统计关联有多强、多稳定？ |
| 4. 个股明细 | 每只股票样本与分数区间 | 哪些股票贡献了样本？ |
| 5. 口径与已知限制 | 全部假设清单 | 结果在什么前提下成立？ |
| 6. 更换回测时间段 | 重新回测入口 | 区间不理想怎么办？ |

## 三、术语表

### 分层回测（Layered Backtest）
把全部"股票×交易日"样本按分数分成几组（桶），分别统计每组未来 60/250 日的**平均收益**和**胜率**（收益>0 的占比）。
若分数有效，桶均收益应随分数升高**单调递增**（如 <40 桶 5% → 40-70 桶 10% → ≥70 桶 20%）。
这是验证"分数→收益"关系的**最直接证据**。注意：样本按月频周频采样，桶之间收益差异需结合样本量看，样本太少的桶结论不可靠。

### 五等分桶（Quintile）
更细的分档稳健性检查：按分数区间 0-20 / 20-40 / 40-60 / 60-80 / 80-100 分 5 档，看收益是否逐档递增。
与三桶的区别：五档能暴露"非线性"（例如只有 ≥80 才有效，或 40-60 与 60-80 无差异）。

### IC（Information Coefficient，信息系数）
分数与未来收益的相关系数，衡量"分数排序 → 收益排序"的预测力。取值 -1~1：

| 区间 | 含义 |
|------|------|
| 0.3~1.0 | 预测力强（罕见） |
| 0.1~0.3 | 中等，有一定参考价值 |
| 0~0.1 | 弱，但方向正确 |
| <0 | 方向反了（分数高反而跌得多） |

### Spearman 秩相关
IC 用的是 Spearman（秩相关）而非 Pearson（线性相关）：只看"分数排名与收益排名是否一致"，
不受极端值干扰。例如分数 60 与 90 的实际收益都是 5%，秩相关仍认为它们一致。

### 池化 IC vs 按股 IC
- **池化 IC**：全部股票的所有日样本合并成一个样本集算一个 IC（样本量大、稳定，但被样本多的股票主导）。
- **按股 IC**：每只股票单独算 IC，再汇总均值/中位数/**正 IC 占比**。
  正占比 >70% 说明分数在多数股票上都有效，而不是少数股票贡献全部结果。
- 两者都看：池化看整体强度，按股看稳定性。

### 周频采样（Weekly Sampling）
相邻交易日的样本"未来 60 日收益"高度重叠（今天和明天对未来 60 日几乎一样），直接统计会严重高估样本独立性。
每 5 个交易日取 1 个样本，重叠率降到可接受水平。代价是样本数减少约 5 倍。

### 策略模拟指标
- **净值曲线**：组合价值从 1 开始复利累计的曲线；基准 = 全部股票等权买入持有。
- **累计收益 / 年化**：区间总收益与按 252 交易日折算的年化收益。
- **最大回撤（Max Drawdown）**：净值从峰值到谷底的最大跌幅，衡量最坏情况（如 -30% 表示曾经从高点跌掉三成）。
- **日胜率**：组合日收益 > 0 的天数占比（基准没有此指标）。
- **换手率**：持仓状态发生变化的交易日占比（0.13 ≈ 平均每 8 个交易日调仓一次），反映交易频率与隐含成本。

### 超额收益（Excess Return）
策略累计收益 - 基准累计收益。**超额 > 0 是策略价值的核心指标**——牛市里策略和基准都涨，只有超额能区分策略好坏。

## 四、图表怎么读

1. **净值图（第 1 节）**：先看基准（虚线）判断区间行情（2023-2026 为整体上行段）。再看两条策略线是否在下跌段更抗跌（回撤小）、在上涨段不落后。若策略线长期在基准下方，说明按分数交易的择时在赔钱。
2. **分层柱状图（第 2 节）**：从左到右看柱子是否"阶梯上升"。250 日柱（长周期）比 60 日柱（短周期）更能反映基本面驱动；短周期受市场情绪干扰大，不单调也不必过度解读。
3. **IC 表（第 3 节）**：先看正占比（>70% 为佳），再看按股均值（>0.1 为佳），最后看池化 IC。三者同时为正是"分数有效"的最强证据。
4. **散点图（第 3 节）**：横轴分数、纵轴未来 250 日收益。理想形态是"左下到右上"的斜带；均匀云团表示无关联；"左上到右下"表示方向反了。
5. **个股明细（第 4 节）**：`样本数` 少的股票（如 2023 年上市的次新股）对全局贡献小；`首个分数` 越晚的股票越拉高策略模拟的公共起点。

## 五、常见误区

1. **误区：策略跑不赢基准 = 分数无效。** 分层回测和 IC 才是"分数有效性"的检验；策略模拟额外叠加了阈值、持仓规则、等权假设，跑不赢只说明"简单规则交易"不好用，不代表分数没有预测力（本报告真实结果正是如此：分层单调、IC 为正，但两个策略超额均为负）。
2. **误区：牛市里策略涨了 = 策略有效。** 必须看超额收益；基准都在涨，跟上基准不算本事。
3. **误区：历史分数曲线可以当"历史验证"。** 报告（单股）中的历史曲线是"当前参数视角"（含未来信息），只有本回测的 PIT 分数才可用于验证。两者在报告中有明确标注区分。
4. **误区：五等分桶 = 按样本数五等分。** 当前实现是固定分数区间分 5 档（0-20/…/80-100），与统计口径的"五分位分组"不同，对比时注意口径。
5. **误区：跨股票比分数。** 分数是"相对自身历史"的百分位口径，A 股的 70 分和 B 股的 70 分不可直接比较。

## 六、口径假设清单（结果的前提）

- 财务披露时点：T 年年报次年 5 月 1 日生效（A 股年报披露截止 4/30），1-4 月用 T-2 年报。
- PE/PB 区间：截至切片起点的全部历史日不复权价 ÷ 已生效 EPS/BPS 的 10th/90th（expanding window），每年 5/1 重算；区间样本 <50 的天不出分数（warmup 期）。
- 历史 PE/PB 用**不复权真实交易价**（前复权价随除权整体缩放会失真）；收益/MA/量能因子用前复权序列（日收益自洽）。
- 无历史 EPS 的交易日：PE/PB 因子计中性分，**禁止用当前 EPS 反推**。
- 收益为前复权收盘价收益（含分红除权效应），不另计现金分红与交易成本。
- 股息率因子：未提供 DPS，因子缺失、权重自动再分配。
- 信号滞后 1 日（T 日信号 → T+1 日持仓）。
- 策略 B（百分位）：当日分数 ≥ 自身历史 p80 买入 / ≤ p20 卖出，阈值按年度切片 PIT 重算（样本 ≥50）。

## 七、更换回测时间段

默认净值区间从"全部股票首个分数的最晚日期"开始（2023 年前后上市的新股会拉高起点）。
如需避开特定行情段（如只测 2023-2026 之外、或从 2018 年开始）：

```bash
# 命令行方式
python scripts/run_backtest.py --start 2020-01-01        # 截断起点
python scripts/run_backtest.py --stocks 600887,601899    # 指定股票子集
```

或启动本地服务在页面上提交（报告第 6 节表单 / 主页表单）：

```bash
python scripts/backtest_web.py     # http://127.0.0.1:8643
```

注意：`--start` 只截断展示与统计起点，PIT 分数与区间仍从数据起点计算（保证无未来函数）；
更早起点下，尚未上市/无分数的股票不持仓，基准仍包含全部股票。
