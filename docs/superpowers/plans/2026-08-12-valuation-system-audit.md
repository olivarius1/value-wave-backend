# 估值体系审计：未来函数 / 分数-股价关系 / 合理性评估

> **状态:** 分析文档（2026-08-12），供后续 /plan 转实施计划
> **范围:** 全量 44 只 watchlist 的估值评分体系（scoring_engine / build_report / financial_fetcher / scan_watchlist / summary_report）

**结论速览：**
1. **"当前分数"无未来函数**（拿今日 PE 与截至今日的历史分布比，方法论正确）；**"回测曲线"有未来函数**（历史分数偷看了未来信息），导致回测图存在"自证错觉"，不能当作历史验证。
2. **无传统意义的过拟合**（系统没有训练/拟合过程）；真正的风险是人工调参的主观偏差（8 套权重预设 + 4 只手动校准区间）。
3. **分数本质 = 股价在其自身历史估值区间中的位置**（分段线性负相关）+ 与价格无关的噪声项（量能/波动率）+ 常数项（基本面因子）。分数不是股价之外的新信息，而是股价的重新标定。
4. **核心缺失：从未验证分数与未来收益的关系**——这是判断"估值标准是否合理"的唯一途径，目前无证据。

## 1. 未来函数（look-ahead bias）审查

| # | 位置 | 问题 | 严重度 |
|---|------|------|--------|
| 1 | `financial_fetcher.py:448-451` `compute_valuation_range` | PE/PB 区间 = **整段 10 年 K 线（含最新一天）**的 10th/90th 百分位，作为全局常数应用于回测每一天 → 2016 年的分数用了 2026 年才知道的区间边界 | 🔴 高 |
| 2 | `financial_fetcher.py:216-230` `auto_fill_factors` | ROE（10 年报均值）、毛利率稳定性（标准差）、营收增速（最新年报同比）为**当前算出的常数**，全程恒定套用于历史每一天 | 🔴 高 |
| 3 | `scan_watchlist.py:297-303` / `build_report.py:101` | `eps_growth` 用最新年报净利润复合增速，作为 PEG 因子**恒定**应用于整个回测序列 | 🔴 高 |
| 4 | `scoring_engine.py:517-520` `compute_daily_scores` | `eps_series.get(year)` 让回测中某年全年即用当年年报 EPS，但年报实际次年 3-4 月才披露 → 披露滞后 3-15 个月 | 🟡 中 |
| 5 | `scoring_engine.py:525` | 无历史 EPS 序列时回退 `pe_ttm = close/latest_price × latest_pe`：用**今天**的 EPS 反推历史 PE/PB（现大多已有 pershare_data，影响在缩小） | 🔴 高（存量） |
| 6 | `kline_cache.py`（腾讯财经 API） | **前复权** K 线会随最新除权重写全部历史价格，历史价格本身是"事后"口径 | 🟡 低 |
| 7 | `scoring_engine.py`（dps 参数） | 股息率因子 `dps/当日价` 用当前分红政策回推历史每日股息率 | 🟡 低 |

**自证错觉（最重要推论）：** 回测曲线看起来像"历史验证"（过去低分后来上涨），但历史分数本身包含未来信息（全局区间 + 当前基本面因子），**回测漂亮不能证明模型有效**。图上历史点不是当时可得的实时分数。

## 2. 过拟合评估

- 系统**无训练过程**：权重是 8 套人工预设、区间是百分位、阈值是经验值 → 不存在经典过拟合（无训练集/测试集概念）。
- 真正的风险：**人工调参的主观偏差**。手动校准区间（紫金 PE 8.3-18、神火 4.8-16、云铝 9-22、宝丰 8-20）和权重配比（PE 28%、PEG 20%…）反映设计者信念而非数据证据 → 模型"拟合了你的预期"而非"拟合市场规律"。

## 3. 分数与股价：本质区别与数学关系

**本质区别：**
- 股价 = 市场交易出的绝对价格，受 EPS 增长、股本变动、情绪、流动性共同影响，跨股票不可比。
- 分数 = 把当前价格放入"自身历史估值分布"重新标定，**剥离盈利增长与股本变化影响**，归一化到 0-100。
- **但分数 90% 是股价的单调函数**，不是独立的新信息。

**数学关系（参数固定时，PE 因子分）：**

\[
s_{pe} = \max\left(5,\; 100 - 100 \times \frac{P/EPS - pe_{min}}{pe_{max} - pe_{min}}\right)
\]

各因子与股价 P 的关系：

| 因子 | 关系 | 说明 |
|------|------|------|
| pe / pb | P 的分段线性递减（5 分封底） | 斜率 \(-100/(每股值 \times 区间宽)\) |
| peg | P 的阶梯递减 | 6 档（PEG<0.8→95 … >2.0→20） |
| dividend_yield | \(DPS/P\) 反比例递减 | 仅 cyclical 等模型 |
| ma | 围绕 MA20/MA60 折线 | 均线上方递减、下方递增——**唯一让"跌过头分数反而降"的因子** |
| vol / vola | 与 P 无关 | 量能、振幅噪声项 |
| 基本面因子（roe/毛利率稳定性/商品偏离/产能利用率等） | 常数 | 不随交易日变化 |

**总分表达式：**

\[
Score(P) \approx \underbrace{-\alpha \cdot P + \beta}_{\text{pe+pb+peg+股息率（权重约 40-70%）}} + \underbrace{f_{ma}(P)}_{\text{约 10-20%}} + \underbrace{\text{噪声} + \text{常数}}_{\text{量能/波动/基本面}}
\]

**可验证推论：**
1. 同一股票、参数不变时，**股价涨 10% 分数必降约 3-8 分**（视权重与区间宽度）。例：神火 PE 15.1、区间 4.8-16.0 → PE 因子斜率 ≈ -6.5 分/倍PE，涨 10% 时 pe+pb+peg 合计约降 2-4 分。
2. 任意报告的分数曲线与股价曲线基本呈**镜像关系**。
3. **跨股票分数不可比**：星宇 84.9 只代表"处于自身历史底部 15%"，不代表比神火 32.8 便宜 2.6 倍。这是相对估值（percentile），不是绝对估值。

## 4. 合理性评估

**合理之处：**
- 相对估值框架正确（估值应与自身历史比）
- 10th/90th 百分位稳健，抗极端值
- 历史 EPS/BPS 真实序列（Phase 1b）让历史 PE/PB 口径可信
- 多因子加权有基本面逻辑，5 档状态划分清晰
- 亏损股 PE 为负给 50 分中性、超区间 5 分兜底是合理防御

**三个硬伤：**
1. **从未验证分数与未来收益的关系**：无 IC 检验（分数 vs 未来 1/3/12 月收益相关性）、无分层回测（70+ 组 vs 40- 组的未来收益差）、无策略模拟 → "80+ 分预示上涨"无证据。
2. **状态阈值（80/70/40/20）是经验值**，未用收益数据校准。
3. **权重是信念不是证据**：PE 28% 还是 20% 无数据支撑。

## 5. 优化建议（按优先级，供 /plan 拆解）

### P0 — 正确性（消除未来函数，让回测曲线可信）
- [ ] **滚动窗口区间**：回测每日只用"截至当日"数据计算 10th/90th 区间（expanding window 或按年切片重算），可 5 年抽样加速
- [ ] **财务因子滞后化**：EPS/ROE/增速按披露时点（次年 4 月底）生效，而非年初
- [ ] **图表标注口径**（最小改动兜底）：图注改为"当前参数视角回测（含未来信息，仅展示）"

### P0 — 有效性验证（回答"是否合理"的唯一途径）
- [ ] **`validate_score.py`**：对 44 只股票计算 ① 分数与未来 60/250 日收益的 IC；② 按分数分层（<40 / 40-70 / 70+）的平均未来收益；③ 简单规则策略模拟（70+ 买入 / <40 空仓 vs 持有基准）→ 用结果决定阈值与权重是否调整

### P1 — 可比性与稳健性
- [ ] 报告增加 **z-score**（(当前分-历史均值)/历史标准差），辅助跨股票比较
- [ ] **双窗口区间**（5 年/10 年并行）或按基本面 regime 分段，避免不同基本面时期共用同一区间

### P2 — 因子层
- [ ] 单因子 IC 检验，剔除长期无效因子（如 vola 对多数股票可能只是噪声）
- [ ] 阈值动态化：用历史分位数（20th/80th）替代固定 70/40

### 明确不建议
- ❌ 机器学习拟合权重 / 引入外部因子库：44 只样本太小，任何拟合都会真过拟合，且破坏现有"可解释、可手动校准"优点。

## 6. 验证方法（如何复现/确认上述结论）

1. **分数-价格负相关**：任取一份报告，对 `VALUATION_DATA.data` 计算 score 与 close 序列的 Pearson 相关系数，预期 **< -0.5**（镜像验证）。
2. **未来函数影响量化**：用某历史日（如 2020-01-01）之前的数据快照独立重算该日分数，对比当前报告同日分数 → 差异即未来函数引入的偏差量（预期全局区间导致 ±5~15 分差异）。
3. **披露滞后影响**：将 eps_series 映射改为 `year-1` 后重跑，对比评分变化。
4. **区间敏感性**：将 pe_min/pe_max 改为 5th/95th 分位或手动区间，观察评分分布变化幅度。
